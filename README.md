# ハジケマージ！

スマートフォン縦画面向けの、ピンボールとマージゲームを組み合わせたカジュアルゲームです。

プレイヤーは発射ボタンを長押しし、押した長さに応じた勢いで「ハジケタマ」を発射します。同じレベルのハジケタマ同士をぶつけて進化させ、連鎖マージとハイスコアを狙います。

## MVPの中心要素

- スマートフォン縦画面固定
- 右側の発射レーン
- ボタン長押し時間による発射速度の変化
- 発射物そのものがマージ素材
- 同レベル同士の接触で1段階進化
- 固定バンパーによるピンボール挙動
- NEXT 3個表示とバッグ方式の出現制御
- コンボとスコア
- 危険ラインを2秒越えるとゲームオーバー
- 最大レベル完成時のボーナスと球の退出

## 開発方針

まずは仮素材を用いて、物理挙動とマージの手触りを検証できるMVPを作成します。ゲームバランスに関わる値は外部設定へまとめ、コード変更なしで調整できる構成を推奨します。
